## 🇬🇧 English

A C# Windows Forms application that displays my **top 4 singers**, each with a photo and a button.

### Preview

The interface is made up of four columns, each containing:

- the artist's photo
- a colored button with the artist's name
- a panel below (used to display information)

### The 4 Artists

| Artist        |
|---------------|
| Central Cee   |
| NBA YoungBoy  |
| Cardi B       |
| MC Kako       |

### Technologies

- **Language:** C#
- **Framework:** .NET (Windows Forms)
- **IDE:** Visual Studio

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/jeanbaptistesteeve324-hash/Top4Singers-WinForms.git
   ```
2. Open the `.sln` file in Visual Studio.
3. Restore the NuGet packages if necessary.
4. Press **F5** to build and run the application.

### Usage

Click an artist's button to interact with their column.

### Project Structure

```
Top4Singers-WinForms/
├── Top-4-Cantores.sln        # Visual Studio solution
├── Top-4-Cantores/
│   ├── Form1.cs ... Form5.cs # Application windows
│   ├── Program.cs            # Entry point
│   ├── Resources/            # Artist images
│   └── Top-4-Cantores.csproj # Project file
└── README.md
```
